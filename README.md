# CoGom FE

React 19, TypeScript, React Three Fiber, Three.js, Drei, Zustand로 구현한 3D 스터디 카페입니다. 쿼터뷰 공간에서 곰돌이를 움직이며 개인 집중 타이머, 완료한 일 포스트잇, 근처 친구 깨우기를 사용할 수 있습니다.

화면은 Paper Wireframe Kit에서 확인한 종이 카드, 가는 테두리, 손글씨 포인트를 적용한 대시보드로 구성했습니다. 3D 카페를 넓게 배치하고 사이드바는 기본으로 접어 둡니다. 상단 **메뉴 펼치기/접기** 버튼의 선택은 브라우저에 저장되어 다음 방문에도 유지됩니다. 메뉴에서 카페, 집중 타이머, 친구 목록, 작은 성취로 이동하며, **공간 넓게 보기** 버튼으로 카페 영역을 더 확장할 수 있습니다. 좁은 화면에서는 도구와 성취 카드를 세로로 정렬합니다. Figma MCP의 원본 노드 접근이 거부되어 브라우저에서 컴포넌트를 확인한 뒤 CoGom의 곰돌이 공간과 기능에 맞게 시각적으로 재구성했으며, 원본과 픽셀 단위로 일치하는 구현은 아닙니다.

## 실행과 빌드

Node.js 22.12 이상에서 실행합니다.

~~~powershell
npm ci
npm run dev
~~~

[로컬 카페](http://127.0.0.1:5173/)를 열면 로그인 화면이 나옵니다. 회원가입과 로그인, 실시간 기능은 함께 실행한 CoGom BE의 8080 포트를 사용합니다. Vite가 `/api`와 `/ws`를 백엔드로 프록시합니다.

~~~powershell
npm run typecheck
npm test
npm run build
~~~

빌드 결과는 `dist`에 생성됩니다. 개발 서버에서 [헬스 체크](http://127.0.0.1:5173/api/v1/health) 응답으로 프록시 연결을 확인할 수 있습니다.

## 체험 모드

첫 화면에서 **둘러보기**를 누르면 샘플 곰돌이 세 명과 포스트잇이 있는 체험 모드로 들어갑니다. 타이머, 이동, 완료한 일 등록을 로컬에서 사용할 수 있습니다.

- 휴식 중에 카페 화면을 클릭한 뒤 방향키로 내 곰돌이를 움직입니다. 화면 아래 화살표 버튼도 클릭하거나 길게 눌러 이동할 수 있습니다. 닉네임이나 완료한 일을 입력하는 동안에는 입력창을 조작합니다.
- 내 곰돌이가 걸으면 나무 바닥을 밟는 소리가 납니다. 참가자의 발밑에는 곰 발자국과 작은 원형 파장이 나타났다가 사라집니다. 좌석으로 돌아가는 순간에는 발걸음 효과를 만들지 않습니다.
- 공간을 드래그하면 시점을 바꾸고, 휠이나 두 손가락으로 확대·축소합니다. 오른쪽 아래 **+/−** 버튼도 사용할 수 있으며, **내 곰돌이**로 내 캐릭터를 가까이 보고 **카메라 시점 초기화**로 방 전체 시점으로 돌아갑니다. 메뉴나 화면 크기를 바꿔도 상대적인 확대 비율을 유지합니다.
- 공간 상단 **전체 화면** 버튼은 3D 카페를 화면 전체로 엽니다. 브라우저의 Fullscreen API를 우선 사용하고, 지원하지 않는 환경에서는 브라우저 영역을 가득 채웁니다. 전체 화면에서는 **타이머만** 표시하고, 타이머를 누르면 집중 시작·일시정지를 전환합니다. **Esc**로 돌아갑니다. 방향키·Space·휠 조작은 그대로 사용할 수 있습니다.
- 카페 화면을 클릭한 뒤 **스페이스바**를 누르면 0.8초 동안 점프합니다. 방향키로 이동하면서 점프할 수 있고, 이동 버튼 옆의 **점프** 버튼도 사용할 수 있습니다. 키를 길게 눌러도 한 번만 점프하며, 착석·노크·점프 중에는 다시 점프하지 않습니다. 입력창과 일반 버튼의 스페이스 동작은 유지합니다. 실시간 방에서는 서버가 점프 시작 시각을 공유합니다.
- **앉아서 집중하기** 또는 공간 상단 **집중하기**를 누르면 지정된 좌석으로 돌아가 25분 집중을 시작합니다. 착석 중에는 방향키와 이동 버튼이 잠깁니다. **일어나서 쉬기**, 공간 상단 **일어나기**, 타이머 종료로 다시 걸을 수 있습니다. 일시정지는 남은 시간을 보관하고 초기화 버튼은 휴식 상태와 25분으로 되돌립니다.
- 공부 중에는 필기(`writing`), 헤드폰(`headphones`), 생각 정리(`thinking`), 독서(`reading`), 타이핑(`typing`) 중 하나를 무작위로 재생합니다. 약 20초마다 직전과 다른 스타일로 바뀌며, 연필·헤드폰·책 등의 소품과 동작을 함께 표시합니다.
- 완료한 일을 최대 70자로 적고 **완료하고 붙이기**를 누르면 벽면 포스트잇과 목록에 추가됩니다.
- 나와 친구가 모두 휴식 중일 때 친구의 1.8 거리 이내로 이동한 뒤 곰돌이를 클릭하거나 친구 목록의 종 버튼을 누릅니다. 보내는 곰돌이가 상대를 향해 1.6초 동안 팔로 노크하고 노크 소리가 납니다. 이 동작 중에는 이동과 추가 깨우기가 잠기며, 같은 친구에게 다시 알림을 보내기까지 5초의 간격이 있습니다.
- **알림 미리보기**로 수신 토스트와 알림음을 확인합니다. 상단 스피커 버튼은 발걸음·노크·알림 소리를 함께 켜고 끕니다. 소리는 Web Audio로 합성하며 화면 클릭, 키 입력 등 사용자의 첫 조작 후 활성화됩니다.

## 두 브라우저 창에서 함께 사용

1. CoGom BE를 실행하고 두 브라우저 창에서 같은 로컬 카페 주소를 엽니다.
2. 각 창에서 로그인하거나 **둘러보기**를 선택해 카페를 엽니다. **실시간 입장**을 누르고 서로 다른 닉네임을 입력합니다.
3. **실시간 연결** 표시와 두 참가자를 확인합니다. 한 창에서 이동하거나 타이머를 시작하면 다른 창의 곰돌이 위치, 지정 좌석과 공부 스타일에 반영됩니다. 서버가 약 20초마다 새 공부 스타일과 시작 시각을 보내 두 창의 동작을 맞춥니다.
4. 두 참가자가 휴식 중인 상태에서 한 참가자가 가까이 다가가 다른 곰돌이를 클릭합니다. 서버가 깨우기를 승인하면 보내는 곰돌이의 방향·노크 동작·노크 소리가 공유되고, 수신 창에는 보낸 사람 이름이 포함된 알림과 알림음이 나타납니다. 각 창에서 한 번 조작하고 소리를 켠 상태로 확인합니다.
5. 완료한 일을 등록하면 같은 방의 벽면 포스트잇에도 공유됩니다.

실시간 방은 최대 6명이 사용하며, 서버가 연결별 사용자 ID를 부여합니다. 연결이 끊어지면 현재 화면을 체험 모드로 전환하고 재연결을 시도합니다. 재연결 후에는 서버의 현재 참가자와 포스트잇을 받아 화면을 갱신합니다. 서버는 메모리에 상태를 보관하므로 서버 재시작 시 참가자와 완료한 일 데이터가 초기화됩니다.

메시지 필드와 검증 규칙은 [WebSocket 명세](../CoGom_BE/docs/websocket.md)에 정리되어 있습니다.

## 곰돌이 모델과 애니메이션

제공된 `character_source.glb`를 `public/models/bear.glb`에 배치하고 `useGLTF`로 불러옵니다. 모델을 참가자별로 복제해 각자의 위치와 타이머 상태를 적용합니다.

제공 파일에는 본 기반 리그와 애니메이션 클립이 없습니다. 현재는 복제한 원본 메시의 팔·다리 부품에 회전 중심 그룹을 추가하고, 코드에서 `AnimationClip`과 키프레임 트랙을 만들어 다섯 공부 스타일, 휴식, 노크를 표현합니다. `useAnimations`의 AnimationMixer가 클립을 재생하고 상태 변경 시 부드럽게 전환합니다. 이는 제공 모델을 움직이기 위한 절차적 애니메이션이며, 서버가 전달한 `studyStyle`, `styleChangedAt`, `knockUntil`로 동작 종류와 재생 시점을 맞춥니다.

- `app/`은 진입점, 화면 전환, 대시보드 배치, 공통 화면 스타일을 관리합니다.
- `features/`는 각 기능의 UI, 스타일, API와 훅을 함께 둡니다. `useRoomSession`은 입장과 연결 종료를, `useFocusTimer`는 집중 타이머 표시와 조작을, `useRoomSound`와 `RoomToast`는 오디오와 알림을 담당합니다. `PostItsPanel`은 입력과 목록을 관리하며 WebSocket으로 동기화되는 방의 포스트잇 상태와 등록 동작을 사용합니다.
- `shared/`에는 인증과 스터디룸에서 함께 쓰는 곰 마크와 백엔드 주소 유틸을 둡니다. 개발 서버 및 HTTP·WebSocket 프록시는 루트의 `vite.config.ts`에서 설정합니다.
